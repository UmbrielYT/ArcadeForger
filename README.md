# ArcadeForge

A free, static browser arcade built with plain HTML, CSS and JavaScript.

## Included
- Responsive dark/light UI
- Search and category filters
- Favourites stored in localStorage
- Local coins, stats, achievements and high scores
- Six playable games:
  - Neon Snake
  - Crystal Clicker
  - Reaction Rush
  - Memory Match
  - Space Dodger
  - Tic Tac Toe
- No backend, paid APIs, accounts or API keys required

## Run locally
Open `index.html` in a browser.

## Publish for free
Upload `index.html`, `style.css`, `script.js`, and this README to a public GitHub repository, then enable GitHub Pages in the repository's Pages settings.
